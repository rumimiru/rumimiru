## Featured Project

### 🎲 Valorant Agent Randomizer

A scrolling web app for indecisive multi-role players. Pick a role, roll a random VALORANT agent, and customize which agents are in your pool.

- 🎯 Role-based randomizer (Initiator, Controller, Duelist, Sentinel, or Flex)
- 🛠️ Customizable agent pool, so you only roll the agents you own
- 🤝 Agent team compatibility picks
- 🎵 Music player with a waveform background that reacts to the audio

**Explore the project:** [Valorant Agent Randomizer](https://valo-agent-randomizer.vercel.app/)

## Partnered Project:
### 🩺 NursePath

**Project Lead:** Rance Pascua

A clinical reference progressive web application designed for student nurses. It provides vital signs reference ranges, over-the-counter medication lookup, and common nursing calculators.

- 📱 Progressive Web App (PWA)
- 📴 Works offline after the first load
- 🩺 Designed to support quick access to clinical references
- 🏫 Currently under faculty review for adoption at Universidad de Dagupan

**Explore the project:** [NursePath](https://block9nurseapp.vercel.app/)
